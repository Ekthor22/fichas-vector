# Fichas Técnicas Grupo Vector

App web instalable (PWA) para buscar fichas técnicas de los 171 SKU del Manual Técnico Vector v2.2 por código Vector (1202-61), SKU Softland (120261) o descripción, y descargar el PDF.

Edición cliente: sin clase ABCD ni precios.

**Publicar:** Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
URL: https://ekthor22.github.io/fichas-vector/
